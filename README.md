# 基于 Unity 的卡牌战斗游戏设计与实现

本项目为本科毕业设计《基于 Unity 的卡牌战斗游戏设计与实现》的配套项目文件。项目基于 Unity 引擎开发，是一个 2.5D 卡牌战斗游戏 Demo。

## 项目简介

本项目围绕“卡槽布阵、结构约束、灵感合成、局外事件推进”等核心机制展开。玩家在局外场景中选择事件，获得卡牌或配方，并进入战斗；在战斗中通过拖拽卡牌进行卡槽布阵，系统按槽位顺序进行战斗结算，并在战斗结束后完成奖励回流。

## 核心功能

- 局外事件选择与天数推进
- 卡牌拖拽与卡槽布阵
- 卡牌接口匹配与放置判定
- 按槽位顺序进行战斗结算
- 防反、追击、多段攻击、力量等特殊机制
- 红、黄、蓝三类灵感资源与卡牌合成
- 战后奖励与局外流程回流

## 技术实现

- Unity
- C#
- ScriptableObject 数据配置
- Unity UI / EventSystem
- DOTween 动画反馈

## 项目结构

- `Assets/`：项目资源、脚本、场景与预制体
- `Packages/`：Unity 包配置
- `ProjectSettings/`：Unity 项目设置

## 运行方式

1. 使用 Unity 打开本项目。
2. 推荐使用与项目开发版本一致或接近的 Unity 版本。
3. 打开开始场景或 Hub/Battle 相关场景运行。
4. 可在 Releases 中下载已打包的演示版本。

## 说明

本项目为毕业设计 Demo，重点用于展示核心玩法机制和系统实现流程。当前版本主要完成了局外事件、局内战斗、卡槽布阵、灵感合成和奖励回流等基础闭环。
